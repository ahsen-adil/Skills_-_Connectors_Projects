# Source Document Placed in Google Drive

This document was placed in Google Drive prior to running the prompt. It contains source notes on AI Agents:

- Generative AI vs. Agentic AI: Generative AI generates passive text, while Agentic AI actively pursues goals as an autonomous entity that perceives, reasons, and acts.
- Core Architecture: The Perceive-Reason-Act loop consists of Planning (Chain-of-Thought, Tree-of-Thoughts), Memory (short-term context window and long-term vector DBs/RAG), and Tool Use (APIs, code execution, web search).
- Multi-Agent Systems (MAS): Agents operate in specialized teams: Orchestrator (workflow & task delegation), Worker (technical execution/coding), Reviewer (quality validation).
- Safety Guardrails: Human-in-the-loop (HITL) checkpoints for high-stakes actions.
