# Study Notes — AI Agents & MCP

## What Are AI Agents
AI Agents are systems that can understand a goal, make decisions, use tools, and complete tasks with limited human intervention. Unlike simpler programs, they don't just follow a script — they reason about the best way to reach the goal they're given.

**Key terms:** AI agent, goal, decision-making, tool use, autonomy

## Automation vs. AI Agents
Automation follows predefined rules — it executes fixed logic set in advance ("if X, then Y"). AI agents, by contrast, can reason about what to do next, choosing their own path toward a goal rather than following a rigid script. This makes agents more flexible but also less predictable than plain automation.

**Key terms:** automation, predefined rules, reasoning, flexibility, predictability

## Model Context Protocol (MCP)
MCP allows AI models to connect with external tools and data sources in a standardized way. Instead of building custom, one-off integrations for every tool an AI system needs, MCP provides a common protocol so models can plug into different tools and data sources consistently.

**Key terms:** MCP, standardization, external tools, data sources, integration

## Verification and Safety in AI Systems
Good AI systems should include verification and safety checks rather than blindly trusting the model's output. Because agents can take autonomous action (not just generate text), safeguards are needed to check outputs and decisions before they're acted on.

**Key terms:** verification, safety checks, trust, autonomous action, safeguards
