# Study Notes — Large Language Models (LLMs)

## Large Language Models (LLMs)
Large Language Models (LLMs) are artificial intelligence models trained on extensive volumes of text data. They are designed to understand and generate human-like language.

**Key terms:** Large Language Models (LLMs), AI model, text generation

## Tokens and Text Processing
Text provided to an LLM is broken down into smaller units called tokens. Rather than analyzing entire sentences at once, the models process input token by token.

**Key terms:** tokens, text processing

## Prompting
A prompt guides the model on how to respond. An effective prompt includes three key components:
- A clear description of the task
- Relevant and useful context
- A clear specification of the desired output

**Key terms:** prompting, context, desired output

## Hallucinations
LLMs can sometimes hallucinate, meaning they produce statements that sound convincing and correct but are actually false. Consequently, any important information generated by an LLM must be verified.

**Key terms:** hallucination, verification

## Review Questions
1. How does an LLM's method of processing text in tokens differ from interpreting complete sentences at once when generating language?
2. How do clear task descriptions, context, and output specifications in a prompt work together to guide an LLM effectively?
3. Why is verification essential when using LLM outputs, especially given their tendency to generate plausible-sounding hallucinations?
